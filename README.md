# Marwa Photo Gallery

A responsive gallery website inspired by the supplied design.

## Pages
- Home
- About
- Gallery
- Contact

## Add your own photos
1. Put your permanent website photos in `images/` and name them `photo1.jpg` through `photo6.jpg`, or change the filenames in the HTML.
2. Open **Gallery** and use **Add Photos** to add photos directly from your device.
3. Added photos are stored in the browser's local storage.

## Hosting
Upload the whole folder to Netlify, GitHub Pages, or any static hosting service.

All navigation buttons are functional and link to their respective pages.
